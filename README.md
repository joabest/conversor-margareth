# Conversor Margareth

Dashboard em HTML para converter mensagens de cotas de consórcio em uma tabela visual.

## Recursos
- Dashboard dark responsiva
- Conversão de texto estilo WhatsApp
- Identificação de AUTO / IMÓVEL e banco
- Crédito, entrada, prazo/parcela e vencimento
- Observações como junção de cotas, VOLTOU e ficha aguardando resposta
- Busca
- Persistência local no navegador
- Exportação CSV

Abra `index.html` diretamente no navegador ou publique via GitHub Pages/Vercel.
